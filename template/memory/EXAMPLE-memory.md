The body holds ONE fact. For `feedback` and `project` types, follow it with the
two lines below so the guidance is actionable, not just descriptive.

**Why:** the reason this matters — usually the error or context that produced it.

**How to apply:** the concrete behavior change next time the situation comes up.

Link related memories with [[their-name]], where `their-name` is the other file's
`name:` slug. A `[[link]]` to a file that doesn't exist yet is fine — it marks
something worth writing later.
